# Full port feature parity matrix

The 91 baseline rows are carried forward from the local 0.4.7 audit. The original and Android source references and behavior are retained. Status overrides reflect checkpoints 0.4.11–0.4.12. “Baseline” means the prior reviewed status still applies and the current phase did not reverify it. IDs are stable for subsequent updates.

For baseline rows, dependencies and licenses follow the cited implementations and the upstream license. Individual external integrations remain subject to license verification before adoption. Checkpoint fixtures target min API 27 and the APK has no native libraries. Device, emulator and live checks remain pending unless a row explicitly records them.
