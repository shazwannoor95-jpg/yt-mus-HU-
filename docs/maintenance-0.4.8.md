# YTM Head Unit 0.4.8 — Legacy romanization

YouTube Music and LRCLIB supply original lyrics without the alternate fields that Unison TTML can carry. In 0.4.7, the renderer tried remote Unison first and skipped Android ICU entirely below API 29. Japanese kanji also deliberately bypassed generic ICU Han readings on newer APIs. The resulting message could refer to romanization, translation or both. The supplied API 27 result establishes that sign-in and original lyrics worked. It does not establish whether Unison returned an error or incomplete data.

0.4.8 uses source readings first, then local readings, and can use Unison for unresolved lines. It keeps original lyrics, line breaks and timing. Untimed YouTube Music lines remain untimed. If Han-only lyrics have no reliable language evidence, use **Settings › Lyrics › Han-only lyrics** to select Japanese or Chinese. Kana context takes precedence over Chinese selection. Unrecognized characters stay in the original script.

- Japanese kana uses a small Hepburn converter. Optional Kuromoji Core 0.9.0 and IPADIC use contextual token readings and pronunciation for kanji and particles. Install through **Settings › Lyrics › Japanese dictionary › Manage › Download**. The exact download is 13,343,016 bytes, displayed as 12.8 MiB, with 14 MiB of free space required for installation. The SHA-256-pinned download is opened as data in a background batch. It is not packaged in the APK or loaded during startup. The heap and device-memory checks apply across performance modes. Under pressure the app preserves kanji and converts available kana.
- Korean uses Korean Romanizer 2.0.1 (MIT). Chinese uses a compact lookup generated from Unicode 15.1 Unihan kMandarin and kHanyuPinyin. It preserves characters with conflicting toneless readings. TinyPinyin (Apache-2.0) is compact but needs extra lexical data for polyphones. Kuroshiro (MIT) needs a JavaScript engine and tokenizer dictionary. Bundled ICU would add code and generic Han conversion is unsuitable for Japanese lyrics. Cyrillic uses a compact mapping for common Russian and Ukrainian letters. Android ICU remains available on API 29+ for other applicable scripts.
- English and Bahasa Melayu still use source-provided translations first, then Unison. No additional verified translation provider was available. Existing Unison request and disk-cache limits remain in place. The cloud workspace could not reach the endpoint through its proxy. The separate on-screen messages now identify missing readings and translation problems independently.

The Japanese tokenizer kept approximately 33 MiB of heap while active in a host JVM test with a 64 MiB heap. Heap growth immediately after initialization was about 38 MiB. This is a host estimate. Android PSS, dictionary installation and uninterrupted music playback on the physical head unit still need a device check.

Gradle passed all 36 tests. The API 27 fixture rendered `sayonara no mae ni` alongside the Japanese title as an untimed YouTube Music line with the local dictionary and no Unison request. Tests also cover mixed scripts, low-memory kana fallback, stale track results, preferences, cached readings and the seek thumb. The signed APK is 1,240,778 bytes, up 211,901 bytes (20.6%). It retains min API 27 and contains no ABI-specific libraries. REA and Craft Anything inspected the Windows installer and compared APK artifacts. Source-level translation behavior was checked against the pinned ytm-rs.
